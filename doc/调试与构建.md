# ODMatrix 调试与构建

## 1. 目标

本文档说明 `ODMatrix` 在本地环境中的引用、构建、部署与验证方式。

## 2. 环境要求

- Windows 开发环境
- Visual Studio
- .NET Framework 3.5 Targeting Pack
- Cities: Skylines 1 本体
- 与项目中引用版本兼容的游戏 DLL

## 3. 本地引用说明

当前项目文件直接引用了本地游戏安装目录中的 DLL：

- `Assembly-CSharp.dll`
- `ColossalManaged.dll`
- `ICities.dll`
- `UnityEngine.dll`

这类引用具有明显的机器相关性，因此在新机器上拉取仓库后，通常需要先修改 `ODMatrix.csproj` 中的 `HintPath`。

## 4. NuGet 依赖

当前 `packages.config` 中的依赖为：

- `CitiesHarmony.API` 2.2.0
- `CitiesHarmony.Harmony` 2.2.2

若依赖未自动还原，需先完成 NuGet 还原后再构建。

## 5. 构建步骤

### 5.1 打开解决方案

打开：

- `ODMatrix.slnx`

### 5.2 检查引用

确认以下内容无黄色警告：

- 游戏 DLL 本地引用
- NuGet 包引用
- 目标框架为 `.NET Framework 3.5`

### 5.3 执行构建

可使用 Visual Studio 直接构建 `Debug` 或 `Release`。

输出目录默认为：

- `bin\Debug\`
- `bin\Release\`

## 6. Mod 部署建议

项目最终产物是 DLL，需要复制到 Cities: Skylines 的 Mod 目录中。

建议调试部署目录：

`%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods\ODMatrix\`

建议将以下文件放入同一目录：

- `ODMatrix.dll`
- 运行时需要的依赖 DLL（如实现期有额外要求）

如果后续引入配置文件、说明文件或图标资源，也应一并复制。

## 7. 基础验证流程

## 7.1 启动验证

- 启动游戏
- 在内容管理器中确认 Mod 可见
- 进入地图或存档
- 查看是否有初始化日志

## 7.2 功能验证

在最小补丁阶段，建议只验证以下内容：

- 补丁是否成功应用
- 候选方法是否被触发
- 日志是否能输出捕获计数

在调试模式阶段，额外验证：

- 是否能够保留原始居民出行记录
- 是否能够保留游客出行记录
- 是否可人工抽样核对 Origin / Destination 与 Purpose
- 原始记录与聚合结果是否一致
- 是否能正确区分 `PrimaryIntent` 与 `Retry`

在导出阶段，再验证：

- JSON 文件是否生成
- 文件命名是否符合预期
- 内容结构是否符合 `doc/数据模型.md`

在正式模式阶段，再验证：

- 网格顺序索引是否稳定
- 压缩整数记录是否可正确还原为导出矩阵
- 路径层对照埋点数量是否持续增长
- 意图层数量与 `PathManager.CreatePath` 对照数量是否存在可解释关系

## 7.3 故障排查

### 常见问题 1：构建失败，找不到游戏程序集

检查：

- `HintPath` 是否指向你的实际安装路径
- 游戏是否已安装且文件完整

### 常见问题 2：游戏中看不到 Mod

检查：

- 输出 DLL 是否复制到正确目录
- 文件夹层级是否正确
- 是否缺失依赖 DLL

### 常见问题 3：Mod 加载但无任何日志

检查：

- 入口类是否被正确实现
- Harmony 初始化是否执行
- 日志调用是否放在实际触发路径上

### 常见问题 4：JSON 导出失败

检查：

- 输出目录是否存在写权限
- 序列化库是否兼容 net35
- 快照对象中是否包含不可序列化字段

## 8. 调试建议

- 初期优先使用最少日志验证关键链路
- 不要在高频补丁中输出大量日志
- 对异常统一捕获并输出简短上下文
- 每增加一个模块，就补一次最小验证

日志策略要求：

- 游戏日志只写启动、关闭、补丁初始化、导出摘要
- 详细调试日志写入本 Mod 独立日志文件
- 调试模式下的人工稽核信息不得污染游戏总日志
- 统计摘要应区分总触发数、主意图数、重试数、游客数和对照埋点数

建议的独立日志目录：

- `%LOCALAPPDATA%\Colossal Order\Cities_Skylines\ODMatrix\Logs\`

## 9. 发布前检查清单

- `Release` 构建通过
- 无本地调试残留开关
- 输出目录与文件命名稳定
- JSON 结构与文档一致
- 基本场景下无明显报错或卡顿
- 调试模式与正式模式的日志行为符合预期
