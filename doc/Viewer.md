# ODMatrixViewer 离线可视化工具架构与设计文档

## 1. 项目概述

**ODMatrixViewer** 是《都市：天际线 1》数据采集 Mod (`ODMatrix`) 的配套离线可视化分析工具。
其核心目标是读取 Mod 输出的高密度微观交通原始数据（CSV格式），将其在由 CSL Map Viewer 导出的静态 PNG 底图上进行高性能聚合与渲染，直观展示城市级别的 OD（起讫点）热力矩阵、潮汐现象与职住辐射范围。

## 2. 技术栈与基础架构

为降低上下文切换的心智负担并实现代码级复用，本项目采用与游戏采集端完全一致的基础技术栈，并坚持“零外部依赖”的极客开发原则。

* **目标框架**：`.NET Framework 3.5`
* **UI 框架**：`WPF` (Windows Presentation Foundation)
* **核心策略**：
* **零第三方依赖**：不引入诸如 CsvHelper 或重型图表库，纯原生实现。
* **结构体复用**：直接复用采集端的 `TravelRecord` 数据模型与 20u 网格离散化逻辑。
* **底层渲染**：摒弃 WPF 沉重的 `UIElement` 视觉树，直接调用 `DrawingVisual` 绘制底层像素/图元。



## 3. 核心功能设计

### 3.1 三维探查模式 (OD Exploration)

* **全局宏观流量**：默认视图，展示全地图所有网格的总活跃度（出+入流量总和）。
* **入度探查 (Inbound)**：在地图上点击选中某一网格（焦点网格）后，展示全市各个角落**来到**该网格的流量热力分布。用于评估商业体、交通枢纽的客流吸引力。
* **出度探查 (Outbound)**：以焦点网格为起点，展示从该处**出发**前往全市各地的流量分布。用于评估居住区的早高峰通勤去向。

### 3.2 自然时间切片 (Time Slicing)

* 利用 CSV 原始数据中的 `RecordTime` (Ticks)，在数据加载时将数据升维聚合为按“自然小时 (0-23)”划分的内存字典。
* 通过 UI 底部/侧边的滑块实时切换小时数据，瞬间重绘地图，用于动态分析早晚高峰的“潮汐现象”。

### 3.3 语义过滤 (Semantic Filtering)

对底层复杂的 `TransferReason` 进行高阶合并，提供四个维度的复选框开关：

1. **通勤与就学**：涵盖 Worker, Student 等。
2. **商业与休闲**：涵盖 Shopping, Entertainment, Tourist 等。
3. **工业与物流**：涵盖 Goods, Oil, Ore 等各类货运。
4. **城市服务与应急**：涵盖 Police, Fire, Garbage 等。

### 3.4 跨城际边界流量投影 (Edge Projection)

针对起点或终点超出标准地图边界 ($\pm 8640u$) 的外部连接（Outside Connections）流量，不予丢弃，也不直接渲染在虚空：

* **射线投影算法**：以地图中心为基准，向越界坐标发射射线，计算与边界的交点。
* **边界网关**：将交点作为“城际流量出入口”，在视觉上用特殊的描边高亮网格渲染，表征跨城过境交通。

## 4. 视觉与渲染引擎设计

### 4.1 解决 Z 轴色彩冲突 (底图去色)

为了防止高对比度的 CSL PNG 底图（包含绿地、蓝水、白路）与热力图发生颜色混叠（变成“脏泥巴”）：

* **灰度化处理**：加载底图时，利用 WPF 原生的 `FormatConvertedBitmap` 将图片强制转换为 `Gray8` 灰度图。
* **暗化叠加**：在灰度图上方可叠加一层半透明黑底，实现类似“夜间仪表盘”的数据突出效果。

### 4.2 热力图语义映射

放弃线性映射，采用适应交通数据“长尾特征”的动态非线性映射：

* **极值截断**：选取当前过滤集合下所有网格流量的 **95% 或 98% 分位数**作为 `MaxRef`，超出的按最大值渲染，避免少数拥堵极值点压垮全局。
* **对数平滑**：使用 `Math.Log()` 进行比例计算。
* **透明度 (Alpha)**：设定上下限（如 20% ~ 85%）。只要有流量即微弱可见；流量达到顶峰也不会完全不透明，确保底层路网走向依然可读。
* **赛博/霓虹色调**：低流量为“幽蓝/青色”，中流量为“亮紫/橙色”，高流量热点为“荧光黄/亮红”。

### 4.3 高性能渲染核心 (Performance Optimization)

* **UI 轻量化**：使用单个继承自 `FrameworkElement` 的容器，内部托管一个 `DrawingVisual`。
* **图元批处理**：遍历内存网格字典，计算屏幕映射坐标，调用 `DrawingContext.DrawRectangle` 批量绘制几万个色块。
* **防内存泄漏命门**：在根据流量生成色块的 `SolidColorBrush` 后，**必须调用 `Freeze()**` 冻结画刷对象，彻底消除 WPF 底层的状态跟踪开销。

## 5. 交互与 UI 布局 (UI/UX)

整体采用经典的**控制台架构**，分为左右两大区域：

### 5.1 左侧边栏 (控制台)

固定宽度，深色背景（Dark Mode），包含：

* **模式选择器**：下拉框（全局/入度/出度）。
* **语义过滤器**：多选 CheckBox。
* **时间滑块**：带有 0-23 刻度的 Slider，可拖动查看分时动态。
* **焦点网格面板**：展示鼠标当前选中网格的绝对逻辑坐标（如 GridX_GridZ）、具体流量数值与构成明细。

### 5.2 右侧主视口 (地图画板)

占据剩余所有空间，支持无限视野探查：

* **布局容器**：设定 `ClipToBounds="True"` 的 `Grid`。
* **图层叠加**：底层为 `Image` (灰度 CSL 地图)，上层为自定义的 `HeatmapVisualHost` (网格渲染层)。
* **变换矩阵**：绑定 `TransformGroup`，接管鼠标滚轮（实现缩放 `ScaleTransform`）和鼠标右键/中键拖拽（实现平移 `TranslateTransform`）。
* **逆向坐标解析**：点击屏幕像素时，通过 `TransformGroup.Inverse` 逆向计算出逻辑网格坐标，触发入度/出度重绘。
